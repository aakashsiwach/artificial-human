Open-source computational mind research

Building a mind as living code.

Artificial Human is an experimental computational artificial-mind project grounded in human neuroscience and cognitive science. It connects a continuously advancing in-memory neural substrate with perception, attention, memory, prediction, regulation, learning, and simulated action.

Explore source ↗ Read README ↗ Research charter ↗
Project boundary Computational research prototype — not a biological human brain.

Neuroscience provides the research foundation. Software modules are testable abstractions and engineering hypotheses, not anatomical replicas. This project makes no claim of consciousness, sentience, subjective experience, or human-level intelligence.

Architecture

How the loop is connected

The runtime advances without incoming HTTP requests or LLM calls. Inputs and actions in this loop are synthetic and simulated.

        v

        v

        |
        v
developmental LIF neural substrate
        |
        v
coarse neural state + simulated body state
        |
        v

        |
        v

        |
        v
outcome, prediction error, reward, memory update
        |
        +----> bounded runtime trace / next tick

Neural simulation

Individual LIF membrane state, signed synapses, conduction delay, event scheduling, deterministic stepping, bounded queues, and inspectable spike traces.

Development and regulation

Stage-dependent connectivity, membrane maturation, STDP-inspired weight updates, homeostatic regulation, conduction-delay refinement, and functional pruning.

Development model →

Action and feedback

A bounded tabular action selector uses body state, working-memory focus, and a coarse neural activity summary. Individual spikes are not directly decoded as motor commands.

Core subsystems

What is in the repository

Each mechanism has explicit code, tests, documentation, and a scoped evaluation or known limitation.

Perception and attention

Explicit input normalization, synthetic modality encoders, bounded relevance/salience ranking, and limited active processing.

Memory and learning

Consent-aware in-memory records, hybrid and temporal retrieval, working memory, episodic recall, relational links, and owner-reviewed consolidation/schema proposals.

Prediction and executive control

World-state prediction, prediction-error reporting, deterministic planning, and explicit approval boundaries.

Language adapter

An optional OpenAI-compatible provider can generate language responses. It is not required for the continuous neural loop or its local evaluation suite.

Metabolism, immune and support systems

Bounded compute/resource budgets, anomaly signals, event scheduling, and reviewable regeneration proposals.

Safe self-development foundation

PR #64 adds immutable evaluation-gap/proposal/evidence contracts, strict patch checks, and fail-closed sandbox integration. No production OS sandbox ships yet.

Evaluation, baselines, and quality checks

Results are kept task-specific. The project does not collapse synthetic scores into a measure of intelligence or biological similarity.
